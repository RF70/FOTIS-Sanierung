# Sanierungskonzept FOTIS

Arbeitsordner für das Sanierungskonzept. Die Gliederung folgt dem Ablauf eines Sanierungskonzepts nach IDW S 6: Lage erfassen, Ursachen analysieren, Maßnahmen ableiten, integrierte Planung erstellen, Umsetzung steuern.

## Struktur

| Ordner | Inhalt |
|---|---|
| `01_Analyse/` | Ausgangslage, Krisenstadium, Krisenursachen, Basisdaten (Jahresabschlüsse, BWA, OPOS) |
| `02_Massnahmen/` | Leitbild des sanierten Unternehmens, Maßnahmenkatalog mit Verantwortlichen, Terminen und Ergebniseffekt |
| `03_Finanzplanung/` | Integrierte Planung (GuV, Bilanz, Liquidität), Szenarien, Fortbestehensprognose |
| `04_Umsetzung/` | Maßnahmencontrolling, Statusberichte, Protokolle |
| `99_Archiv/` | Überholte Fassungen und abgeschlossene Unterlagen |

## Konventionen

- Dateinamen: `JJJJ-MM-TT_Thema_vX.Y.ext`, z. B. `2026-11-22_Krisenursachen_v0.1.md`
- Neue Fassung statt Überschreiben, alte Fassung nach `99_Archiv/`
- Keine personenbezogenen Daten oder Zugangsdaten unverschlüsselt ablegen
